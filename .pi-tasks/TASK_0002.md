### 3.1 `launchers/start.sh` (🚀 Unified Start)
**Shebang:** `#!/data/data/com.termux/files/usr/bin/bash`  
**Inter-process dependency chain:** PulseAudio → virgl → X11 → XFCE

**Step [1/3] Start Services (parallel):**
- **PulseAudio:** Kill stale → `pulseaudio --start --exit-idle-time=-1` → load `module-aaudio-sink` (fallback: `module-sles-sink`) → load `module-native-protocol-tcp auth-ip-acl=127.0.0.1 auth-anonymous=1 port=4713`

- **virgl (auto-detect, 3 tiers):**
  - Tier 1 (android): `virgl_test_server_android &`
  - Tier 2 (angle-vulkan-null): `LD_LIBRARY_PATH=${ANGLE_DIR}/vulkan-null virgl_test_server --use-egl-surfaceless --use-gles &`
  - Tier 3 (angle-vulkan): `LD_LIBRARY_PATH=${ANGLE_DIR}/vulkan virgl_test_server --use-egl-surfaceless --use-gles &`

- **Wake Lock:** `termux-wake-lock`

**Step [2/3] Wait for X11 Socket:**
- Polls `/tmp/.X11-unix/X0` for up to 3 seconds (30 iterations × 100ms)

**Step [3/3] Launch Desktop:**
- **GPU mode** (virgl detected): `proot-distro login arinanox --shared-tmp -- su - admin -c "DISPLAY=:0 PULSE_SERVER=tcp:127.0.0.1:4713 GALLIUM_DRIVER=virpipe MESA_GL_VERSION_OVERRIDE=4.1COMPAT MESA_GLES_VERSION_OVERRIDE=3.1 MESA_NO_ERROR=1 MESA_BACK_BUFFER=pixmap dbus-launch --exit-with-session xfce4-session"`
